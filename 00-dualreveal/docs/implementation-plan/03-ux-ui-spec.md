# UX and UI spec

## Visual direction
- Soft mint background with calm, romantic tone.
- Serif headlines with a refined, editorial feel.
- Deep navy text for contrast and calmness.
- Card-based panels with subtle shadows.
- Small iconography to punctuate sections.

## Typography
- Headings: elegant serif (pick one and apply consistently).
- Body: clean sans-serif for readability.
- Hierarchy: large hero title, medium section headings, compact labels.

## Layout
- Centered single-column layouts for focus.
- Maximum content width around 720 to 840px.
- Generous vertical rhythm between sections.
- Card padding consistent across pages.

## Components
- Primary CTA button with soft shadow and rounded corners.
- Input fields with subtle border and focus state.
- Status panels for waiting and completed states.
- Progress indicator for quiz steps.
- Coupon field always visible with helper text.

## Motion
- Page-load fade and slide for hero content.
- Subtle step transitions in quiz flow.
- Avoid distracting micro-animations.

## Accessibility
- Meet minimum contrast on text and buttons.
- Large tap targets for mobile.
- Clear focus outlines for keyboard users.

## Copy tone
- Warm, respectful, and privacy-conscious.
- Avoid pressure or manipulative language.
