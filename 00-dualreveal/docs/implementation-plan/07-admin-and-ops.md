# Admin and operations

## Admin features
- List reveals with status and timestamps.
- View purchaser email and reveal name.
- Edit question text and save as custom set.
- Reset questions to defaults.
- Toggle coupon campaign flag and set discount parameters.
- Create and revoke personalized coupons.

## Operational needs
- Analytics for conversion and completion rates.
- Support flow for invalid links or refunds.
- Data retention policy and cleanup.
- Simple content updates without redeploy.
- Monitor coupon abuse and ban events.

## Privacy and trust
- Minimize stored data and exposure.
- Avoid showing respondent answers publicly.
- Clear messaging about confidentiality.

## Future enhancements
- Password-protected admin.
- Email delivery for magic links.
- Audit log for changes.
