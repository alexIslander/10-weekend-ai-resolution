# Feedback capture (KISS)

## Goals
- Allow purchasers or respondents to score the experience and leave a short note.
- Store feedback for admin review.

## Placement options
- Option A: On the reveal page after viewing answers.
- Option B: On the goodbye screen after quiz submission.
- Option C: On the dashboard once a reveal is completed.

## Confirmed placement
- Option A and Option B are required.

## Minimal fields
- Thumb up/down
- Optional short text (max 280 chars).

## Admin view
- Show recent feedback entries with rating, date, and reveal id.
