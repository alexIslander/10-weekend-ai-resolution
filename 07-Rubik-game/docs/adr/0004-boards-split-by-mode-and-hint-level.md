# One board per mode and hint level, scored by streak-weighted points

A `Training` run and a `Test` run over the same positions are not comparable, so
each mode carries two boards — twelve in total — presented on the Scores page as
a mode with two columns rather than twelve separate tables.

Score is 10 points per correct answer with a streak multiplier rising to ×5
(50 points per question at the cap), reset by a wrong answer. Time breaks ties
on the board but is never displayed as a countdown, so learning is not rushed.

Rejected: one point per correct (a 57-question run scores 57 either way, which
separates nobody), and time-limited questions (pressure works against
recognition practice).

## Consequences

- A player who wants a top row on `Random / Test` cannot get it by playing at
  `Training`.
- Scores from different pool sizes (`Grouped` groups range from 2 to 8
  positions) are only comparable within the same board, which is what a board
  per mode already means.
